PPTXjs

Render, present, edit and export .pptx in the browser. No jQuery, no server.

Options

Keys: ← → Space, Home/End, F fullscreen, P play. Click the slides first to focus them.

Events

    Drop a .pptx file to open it

    Click a shape to select it, drag it to move, use the handles to resize, double-click to edit text. Del deletes, arrows nudge (Shift = 10px), Ctrl+Z/Ctrl+Y undo/redo, Ctrl+D duplicates. Download the result as .pptx or .odp from the toolbar.

    Headless rendering

    The renderer has no DOM dependency: it runs in Web Workers and in Node.js.

    import { renderToHtml } from "@meshesha/pptxjs";
const { slides, css, width, height } = await renderToHtml(bytes);
slides[0].html;   // HTML of slide 1
slides[0].notes;  // speaker notes

    Slides & notes

      Vanilla JS

      import { PptxViewer } from "@meshesha/pptxjs";
const viewer = new PptxViewer("#slides", { mode: "slideshow" });
await viewer.load("deck.pptx");

      React

      import { PptxViewer } from "@meshesha/pptxjs/react";
<PptxViewer src="/deck.pptx" options={{ mode: "slideshow" }} />

      Vue 3

      import { PptxViewer } from "@meshesha/pptxjs/vue";
<PptxViewer src="/deck.pptx" :options="{ mode: 'slideshow' }" @load="onLoad" />

      Angular

      import { definePptxElements } from "@meshesha/pptxjs/angular";
definePptxElements(); // + CUSTOM_ELEMENTS_SCHEMA
<pptx-viewer [attr.src]="url" mode="slideshow"></pptx-viewer>

      jQuery (v1 compatible)

      $("#result").pptxToHtml({
  pptxFileUrl: "deck.pptx", slideMode: true
});

      <pptx-viewer src="deck.pptx" mode="slideshow" loop></pptx-viewer>
